## 🚀 使用说明

1. 本仓库模板基于 **C++17** 编写，建议使用 `g++ -std=c++17` 编译。
2. 各 `.cpp` 文件为独立可编译单元，可单独复制所需模板到题目中使用。
3. 竞赛时建议将常用模板（快读、排序、最短路等）提前整理至本地笔记，按需粘贴。
4. 若仅需查阅 STL 用法，优先阅读 `STL.cpp` 与 `READMESTL.md`。

## 💡 学习建议

- **入门**：先掌握 `快读快写`、`sort`、`前缀和与差分`、`二分` 等高频基础模板。
- **进阶**：深入理解 `欧氏筛`、`Dijkstra`、`单调队列` 等中等难度模板的原理与适用场景。
- **实战**：结合具体题目练习，避免死记硬背；理解模板背后的思想比背诵代码更重要。
